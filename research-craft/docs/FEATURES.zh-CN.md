# 功能与使用指南

所有功能通过同一个 `research-craft` Skill 使用，安装一次即可。在 Codex 中输入 `$research-craft`，说明目标、材料、允许的操作和想要的产物。

[首页](../README.zh-CN.md) · [English](FEATURES.en.md) · [科研记录与实验管理](RECORDS.zh-CN.md) · [辅助命令](USAGE.zh-CN.md)

下面都是**对话指令**。示例路径请替换为真实文件或附上材料。材料不齐时，可以先要求整理已有依据和缺失信息。

## 01 研究问题与文献

**用途：** 比较研究方法、理解证据与限制，形成有依据的研究缺口。

**准备：** 研究问题、论文或链接、已有笔记、领域与检索范围。在线检索依赖宿主可用工具和网络权限。

```text
请使用 $research-craft 梳理多模态分割中的跨模态对齐问题。
先读 papers/ 和 notes/literature.md，必要时查公开原始论文。
按问题、假设、方法、证据与局限比较，区分文献已知结论和我的推测。
请给出有来源的比较表，以及值得进一步验证的问题。
```

**产物：** 文献比较、具体来源、缺口分析和待验证问题。需要持续积累时，可以同时记录文献、检索式及其关联证据，见[文献与写作记录](RECORDS.zh-CN.md#文献与写作记录)。

## 02 科研代码与日志

**用途：** 定位报错、追踪数据处理与 forward、比较版本和配置差异。

**准备：** 入口、命令、配置、相关日志、完整错误及复现条件。

```text
请使用 $research-craft 排查 models/network.py 中的尺寸错误。
入口是 train.py，配置是 configs/run.yaml，错误见 logs/error.log。
请沿调用链核对实际张量形状，给出代码位置、原因和最小修复建议。
先只读分析；若值得持续追踪，请将问题与下一步记入研究工作区。
```

**产物：** 代码位置、调用或数据流、错误依据、根因候选及验证方法。授权修改后可继续实施局部修复；变更可关联问题、决策和检查结果。

## 03 实验数据与指标

**用途：** 检查异常值、重复与缺失、指标口径、实验可比性，以及改善与退化之间的关系。

**准备：** 原始 CSV、指标定义、样本划分、seed、阈值、配置及 checkpoint 对应关系。

```text
请使用 $research-craft 核查 results/baseline.csv 和 results/proposed.csv。
定义见 notes/metrics.md，划分和配置见 configs/。
先检查成员、阈值、seed 与口径，再分析异常和下降指标。
保留数值精度及具体来源，不修改原数据；将可支持的主张与局限记为证据。
```

**产物：** 可比性判断、异常定位、指标变化与候选解释。整体均值不代表成员一致，差值本身也不能证明模块的因果作用。

## 04 实验设计与补充实验

**用途：** 将假设或审稿关切转成控制实验、消融、重复运行或敏感性分析。

**准备：** 主张、已有结果、竞争解释、已做与待做工作，以及资源限制。

```text
请使用 $research-craft 规划“融合模块提升跨场景泛化”的补充实验。
已有单 seed 结果显示 F1 上升但 Recall 下降，数据在 results/。
请选择最有区分度的实验，说明控制变量、结果判读、资源取舍与优先级。
把计划记录下来，本次不启动训练。
```

**产物：** 有优先级的方案、控制条件与判读方式。可进一步建立包含假设、预期与反证观察、配置和结果位置的[实验记录](RECORDS.zh-CN.md#实验从计划到结果)。

## 05 模型架构绘图

**用途：** 从真实定义整理拓扑，为 CNN、Encoder–Decoder、Transformer、SSM、多尺度与多模态模型制作可编辑论文图。

**准备：** forward、模块或充分的方法定义、已知形状、创新模块、语言及目标尺寸。

```text
请使用 $research-craft 根据 models/network.py 和 method.md 绘制模型图。
目标为 180 mm 双栏，英文标签，保留可编辑 SVG 与结构定义。
先整理节点、连接、融合、跳连、已知维度和训练路径，比较两种不同布局。
请提供实际预览，并分别检查拓扑、信息、视觉、最终尺寸与可编辑性。
```

**产物：** 拓扑整理、布局选择、矢量源、预览与检查说明。未知尺寸明确保留，缺少渲染条件时对应检查列为待完成。图表记录可关联到产生结果的实验。

## 06 科技论文写作

**用途：** 诊断论证、组织章节、明确贡献边界，返回完整改文与关键理由。

**准备：** 原文、相邻段落、方法和结果依据、目标语言与修改范围。

```text
请使用 $research-craft 修改 manuscript/introduction.md。
参考 method.md、related-work.md 和 results/table1.csv。
先诊断缺口、动机与贡献的关系，再给出完整英文修订稿。
保留准确内容，说明主要变化和仍需要补证的主张。
```

| 章节 | 重点处理 |
| --- | --- |
| Abstract | 问题、方法、关键结果与贡献范围 |
| Introduction | 背景、不足、缺口、动机和贡献的衔接 |
| Related Work | 有依据的方法分类与比较 |
| Method | 框架、模块、符号、公式条件和图文关系 |
| Experiments | 条件、控制变量、指标和复现信息 |
| Results | 准确比较改善、退化与不确定性 |
| Discussion / Limitations | 机制、竞争解释、适用条件及局限 |
| Conclusion | 概括已有证据支持的贡献和后续问题 |

**产物：** 诊断、可用稿件、修改理由和证据缺口。可通过论文映射记录章节主张、关联实验和修改位置。

## 07 学术英文与中英翻译

**用途：** 中英互译、学术英文润色、术语统一与语义核对。

**准备：** 完整原文、目标语言、术语表；明确仅语言处理还是同时提出科学建议。

```text
请使用 $research-craft 将 manuscript/method-zh.md 译成自然的学术英文。
术语遵循 glossary.md，保留公式、数字、单位、否定、条件与限定词。
本次仅做语言转换，科学疑点另列；请给出完整译文和歧义术语的说明。
```

**产物：** 完整译文或润色稿、术语说明和语义疑点。需要逐项人工核对时，可以要求中英对照及数字、条件、因果关系检查。

## 08 审稿意见与正式回复

**用途：** 拆解复合意见、规划补证、修改正文并起草逐条回复。

**准备：** 完整评论、当前论文、表图、结果、实际完成事项与资源限制。

```text
请使用 $research-craft 处理 reviews/reviewer2.md，结合 manuscript/ 和 results/。
逐条保留评论，整理关切、技术要求、已有证据及缺口。
区分已完成修改和拟补实验，再起草正文与正式英文回复。
核对数字、图表编号、正文位置，将待完成事项明确标出并记录处理状态。
```

**产物：** 评论处理表、补证计划、正文改文和回复草稿。审稿映射可关联问题、实验和证据，帮助检查遗漏与正文/回信一致性。

## 09 科研指导意见

**用途：** 将“创新不突出”“分析不充分”等反馈转为具体论证或实验修改。

**准备：** 有来源的指导记录、对应原文、研究背景与约束；保留身份或转写的不确定性。

```text
请使用 $research-craft 分析 notes/supervision.md，对照 manuscript/discussion.md。
说明每项意见针对的问题、判断依据和适用条件。
区分科学纠正、行文偏好和本次研究的具体策略，给出修改及验证方法。
不确定的原意单列待确认，重要取舍记录为决策并关联依据。
```

**产物：** 意见与原文对应、修改优先级、具体行动和待确认问题。经验用于支持对当前材料的判断。

## 10 多步骤任务与上下文恢复

**用途：** 多轮排查、改稿、图文联动及跨会话继续工作。

**准备：** 项目、当前目标、相关文件，以及已有 `.research/` 记录。

```text
请使用 $research-craft 继续这个项目的返修。
先查看 .research/ 当前状态和相关活动记录，定位本次需要的正文与证据。
简要说明未决问题，然后处理 Method 的符号一致性。
结束时更新必要状态，保留来源位置和下一步。
```

**产物：** 当前状态、任务相关证据、实际工作结果及下一步。单次问题通常无需建记录，长期项目可使用[科研记录与实验管理](RECORDS.zh-CN.md)。

## 一个好用的请求结构

说明“目标 + 材料 + 范围 + 输出”。例如指出改哪个章节、图用于什么尺寸、比较哪两次实验、是否允许改文件。数据任务补充定义，写作任务补充上下文，审稿任务说明实际完成情况；也可以先要求只读诊断。
